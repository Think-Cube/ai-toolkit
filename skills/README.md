# Skills

Reusable Claude Code skills. Each skill lives in its own directory with a `SKILL.md` file.

To use a skill, copy its directory into your project's `.claude/skills/` folder.

## Available skills

### Cloud Cost Estimation

| Skill | Description |
|---|---|
| [azure-cost-estimation](./azure-cost-estimation) | Estimate and optimize Azure infrastructure costs |
| [aws-cost-estimation](./aws-cost-estimation) | Estimate and optimize AWS infrastructure costs |
| [gcp-cost-estimation](./gcp-cost-estimation) | Estimate and optimize Google Cloud infrastructure costs |
| [multi-cloud-cost-comparison](./multi-cloud-cost-comparison) | Compare costs across Azure, AWS, and Google Cloud |
