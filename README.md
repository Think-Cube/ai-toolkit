# AI Toolkit — Think-Cube

A community-driven collection of AI skills, agents, and tools for Claude Code, GitHub Copilot, and other AI assistants. Built and maintained by the [Think-Cube](https://github.com/Think-Cube) organization.

## What's inside

| Folder | Description |
|---|---|
| [`skills/`](./skills) | Reusable Claude Code skills (`SKILL.md`) |
| [`agents/`](./agents) | AI agents for Claude, Copilot, and others |

## Getting started

### Using a Claude Code skill

1. Copy the desired skill directory into your project's `.claude/skills/` folder.
2. The skill becomes available in Claude Code automatically — invoke it with `/skill-name`.
